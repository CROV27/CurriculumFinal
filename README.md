## Ejecución
Abre esta carpeta con VS Code y ejecuta index.html con Live Server. Alternativa: `python -m http.server 8000` y visita http://localhost:8000. Los módulos ES6 requieren HTTP.

## Estructura
HTML5 en index.html, estilos CSS3 en css/, módulos JavaScript ES6 en js/modules/ y recursos en assets/. main.js inicializa únicamente las funciones de esta etapa.

Consulta LEEME_PRIMERO.md del paquete para los cambios, pruebas y commit sugerido. Esta etapa no representa todavía el examen completo.
